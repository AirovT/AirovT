## How I work

1. **Question every requirement.** Before automating anything I ask whether the step should exist and what happens if we remove it.
2. **Delete, then simplify.** The cheapest automation is the process you no longer need.
3. **Only then automate**, with the least code that works.

I build with AI coding agents inside a strict engineering harness: written specs before code, automated tests and security review.
